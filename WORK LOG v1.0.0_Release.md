# WORK LOG v1.0.0

First official release of WORK LOG, a local-first work and payroll management application.

## Features

- Work registration with automatic payroll calculations
- Lesson-based, hourly, piecework, and direct payment support
- Hourly rate locking with per-record overrides
- Monthly and workplace-specific payroll summaries
- Annual earnings overview
- Work record searching and management
- SQLite backup and restore
- Local data persistence using IndexedDB
- Mobile-friendly interface and PWA support

## Data Management

- Preserve historical payroll amounts.
- Prevent duplicate work records.
- Support database migrations and future feature expansion.
- Keep personal work records in the user's browser.

## Future Plans

- Workplace management and custom sorting
- Work scheduling and calendar integration
- Payroll payment tracking
- Excel integration for grading workload data

Built with HTML, CSS, JavaScript, SQLite, and IndexedDB.
